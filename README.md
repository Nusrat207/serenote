# 🌿 SereNote

**SereNote** is a mindful companion app built with Flutter, designed to help users cultivate emotional awareness, track moods and habits, and find calm through reflection and focus-enhancing mini-games.  

It combines journaling, habit tracking, motivational quotes, and soft gamification — creating a space for gentle growth, balance, and insight.

---

## 🪶 Overview

SereNote allows users to:

- Track and reflect on moods
- Build healthy habits
- Manage daily tasks
- Improve focus and concentration through games
- Personalize their experience through mood-based themes
- Access the app in multiple languages (English & Bangla)

---

## 🌟 Features

### 1. MoodMirror
- Quick mood entry: select from **Joy, Neutral, Sad, Anxious, Angry**.
- Option to type or speak how you feel.
- Sentiment analysis detects mood and suggests quotes & music.
- Integrated APIs:
  - [ZenQuotes](https://zenquotes.io/) for motivational quotes
  - [Deezer API](https://www.deezer.com/) for mood-based music
  - [HuggingFace Sentiment Model](https://huggingface.co/) for mood detection
- App theme colors adapt based on detected mood.

### 2. Journal
- Add journal entries with optional images, title, thoughts, mood, and tags.
- View a list of past entries.
- Share entries via QR code.
- Typical journal operations: edit, delete.

### 3. Task Management
- Expandable calendar view.
- Add and manage tasks for future dates.
- Daily to-do tracking with checkable items.

### 4. Habits
- Track habits you want to build.
- Choose frequency: daily or specific days.
- Mark completion of habits.

### 5. Timer
- Pomodoro timer & regular timer.
- Customize Pomodoro durations.
- Set goals for timer sessions.

### 6. Games
Mind games aligned with focus and mental wellness:
- Snake
- 2048
- Word Search / Wordzee
- Wordle
- Memory Flip / Concentration
- Sudoku
- Slide Puzzle (Number)
- Tetris

### 7. Authentication
- Sign up, login, reset password, and other standard auth features.

### 8. Localization
- Supports English and Bangla languages.

### 9. Profile & Settings
- Update avatar and display name.
- Customize profile settings.
